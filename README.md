# Ostad WebTerminal (وب‌ترمینال استاد)

MT4-style web trading terminal with pluggable broker adapters.

- `web/` – React + Vite + TypeScript frontend (MT4-like UI)
- `server/` – Node/Express + WebSocket backend with broker adapters
  (Demo with live Binance prices, MetaApi MT4/MT5, OANDA, Alpaca, Binance)
